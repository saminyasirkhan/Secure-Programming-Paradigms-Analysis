# 🧮 Secure Programming Paradigms Analysis

This project explores how different programming paradigms influence software security, focusing on Object-Oriented Programming (OOP), Event-Driven Programming (EDP), and Functional Programming (FP).

---

## 📄 Overview

The analysis evaluates how design choices in each paradigm impact security, maintainability, and vulnerability exposure.

---

## 🔍 Key Areas Covered

- Encapsulation and access control in OOP  
- Shared state and concurrency risks in EDP  
- Immutability and safety in Functional Programming  
- Security implications of design patterns  
- Comparison of paradigm strengths and weaknesses  

---

## 🔐 Security Insights

- Poor encapsulation can expose sensitive data  
- Shared state increases risk of unintended behaviour  
- Functional programming reduces side effects and improves predictability  
- Secure design depends on disciplined implementation, not just paradigm choice
